# UI-Do-Or-Dice — Dice Game UI

[![Website](https://img.shields.io/badge/website-live-02aaff?style=for-the-badge&logo=vercel)](https://ui-do-or-dice.vercel.app)
[![Built with](https://img.shields.io/badge/built_with-HTML%2FCSS%2FJS-02aaff?style=for-the-badge&logo=javascript)](https://developer.mozilla.org/)

An interactive and visually engaging dice game user interface, built with HTML, CSS, and JavaScript. The "Do or Dice" concept adds an element of chance and decision-making to a fun, simple game.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Interactive Dice Game** | Roll the dice and test your luck with a simple, fun mechanic |
| **Clean UI** | Modern, visually appealing design focused on the game experience |
| **Responsive Layout** | Adapts seamlessly to desktop, tablet, and mobile screens |
| **Visual Feedback** | Dice animations and interactive elements enhance the user experience |
| **No External Dependencies** | Pure HTML, CSS, and JavaScript — no frameworks required |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- (Optional) A code editor (VS Code recommended)

### Local Development
1. **Clone the repository**
   ```bash
   git clone https://github.com/paoradox/UI-Do-Or-Dice.git
   cd UI-Do-Or-Dice
   ```

2. **Open with Live Server** (VS Code)
   - Right‑click `index.html` → "Open with Live Server"
   - Or simply double‑click `index.html` to open directly in your browser

3. **Visit** `http://localhost:5500` (or the browser tab)

## 🎮 How to Play

The "Do or Dice" game is simple and engaging:
- **Roll the Dice:** Click the button to roll the dice.
- **Chance & Decision:** The outcome of the roll determines your next action or decision.
- **Fun & Interactive:** Enjoy the thrill of chance with a polished, responsive UI.
